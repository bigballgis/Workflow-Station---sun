# MFE Governance Docs Index

This document set defines configuration-driven MFE governance where:

- `Admin Center` manages module registry configuration
- host apps render nav/routes dynamically by runtime config

## Shared Governance Contract

MFE governance aligns with the platform-wide release governance contract defined in:

- [Release Control Plane Blueprint](./release-control-plane-blueprint.md)

Phase 4 and later documents use this blueprint as the canonical release semantics baseline (state model, policy gates, approval and audit vocabulary), while keeping MFE-specific runtime fields and APIs.

## Phase Overview

| Phase | Focus |
|---|---|
| Phase 1 | Config-driven foundation (Admin manage, User Portal dynamic nav/route) |
| Phase 2 | Pilot modules and independent release validation |
| Phase 3 | Core `workflow-mfe` extraction |
| Phase 4 | Multi-host platform governance |
