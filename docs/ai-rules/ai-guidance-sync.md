# AI 指导同步 — Cursor 真源 → Copilot / Kiro / Claude

> 操作手册。约束摘要见 [`.cursor/rules/ai-guidance-sync.mdc`](../../.cursor/rules/ai-guidance-sync.mdc)。

## 目标

把 **Cursor** 的 `.cursor/rules` + `.cursor/skills` 作为唯一真源，自动生成各 AI 工具的原生副本，避免三份正文长期手工维护后内容漂移。

```
.cursor/rules/*.mdc  ─┐
.cursor/skills/*/    ─┴─ sync-cursor-rules.mjs ─┬─ Claude  (CLAUDE.md + .claude/skills)
                                               ├─ Copilot (.github/copilot-instructions.md
                                               │           + .github/instructions
                                               │           + .github/skills)
                                               └─ Kiro    (.kiro/steering + .kiro/skills)
```

## 映射规则

| Cursor frontmatter | Copilot | Kiro | Claude |
|---|---|---|---|
| `alwaysApply: true`（或无 `globs`） | 写入 `.github/copilot-instructions.md` | `inclusion: always` | 根 `CLAUDE.md` `@import` |
| `alwaysApply: false` + `globs` | `.github/instructions/{name}.instructions.md` 的 `applyTo` | `inclusion: fileMatch` + `fileMatchPattern` | 按路径桶写入 `frontend`/`backend`/`deploy/CLAUDE.md` |
| skill 目录 | `.github/skills/{name}/` | `.kiro/skills/{name}/` | `.claude/skills/{name}/` |

## 自动触发

| 触发 | 配置 | 说明 |
|---|---|---|
| 打开工作区 | `.vscode/tasks.json` → `runOn: folderOpen` | 需允许 Automatic Tasks；脚本内单实例锁 |
| Claude 会话开始 | `.claude/settings.json` → `SessionStart` | Claude Code |
| Copilot 会话开始 | `.github/hooks/sync-ai-guidance.json` → `sessionStart` | 未开 Automatic Tasks 时的兜底 |
| CI | `.github/workflows/ai-guidance-sync.yml` | 重生后若有未提交 diff 则失败 |

## 手动同步

```bash
node .claude/scripts/sync-cursor-rules.mjs
```

改完真源后：**跑同步 → 把生成副本一并 commit**。

## 手写内容保护

- 生成文件含 `AUTO-GENERATED by .claude/scripts/sync-cursor-rules.mjs`
- 镜像 skill 目录含 `.synced-from-cursor`
- **无标记**的文件/目录（例如 Kiro 基础 `product.md` / `tech.md`）不会被 prune
- `CLAUDE.md` 仅改写 `<!-- BEGIN cursor-rules:auto -->` … `<!-- END … -->` 区块，手写前言保留

## 开发者检查清单

1. 只改 `.cursor/rules` 或 `.cursor/skills`
2. 本地执行同步脚本
3. `git status` 确认 `.github` / `.kiro` / `.claude/skills` / `CLAUDE.md*` 有对应更新
4. 提交真源 + 生成副本（同一 commit 或紧随其后）
5. CI `AI guidance drift check` 应通过

## 不要做

- 不要只改 `.github/instructions` / `.kiro/steering` / `.claude/skills` 里的正文
- 不要去掉 AUTO-GENERATED 标记来「保留」过期副本
- 不要在未同步的情况下合并改动了 `.cursor/rules` 的 PR（CI 会拦）
