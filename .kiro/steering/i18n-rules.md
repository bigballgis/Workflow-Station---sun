# 国际化规范

## 基本配置

- 框架: vue-i18n v11，Composition API 模式 (`legacy: false`)
- 默认语言: `en`
- 支持语言: `zh-CN`, `zh-TW`, `en`

## Key 命名

- 点分命名空间: `module.section.key`
- 示例: `functionUnit.form.nameRequired`, `common.operationFailed`
- 新增 key 必须与同文件已有 key 命名风格保持一致

## 使用方式

```vue
<template>
  <!-- 模板中 -->
  <span>{{ $t('common.save') }}</span>
  <el-button>{{ t('functionUnit.create') }}</el-button>
</template>

<script setup lang="ts">
const { t } = useI18n()
// 代码中
ElMessage.success(t('common.operationSuccess'))
</script>
```

## 三语言同步

新增或修改任何 i18n key 时，**必须同时更新三个 locale 文件**:
- `locales/zh-CN.ts` (简体中文)
- `locales/zh-TW.ts` (繁体中文)
- `locales/en.ts` (英文)

遗漏任何一个都会导致运行时显示 key 而非翻译文本。

## 绝对禁止

- 禁止在模板或代码中硬编码用户可见的中文/英文字符串
- 禁止只更新一个 locale 文件而忘记其他两个
- 禁止使用不存在的 i18n key（新增前先确认命名空间一致性）
