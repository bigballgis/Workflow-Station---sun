# JPA 实体规范

## 标准注解组合

```java
@Entity
@Table(name = "dw_function_unit")
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
@EqualsAndHashCode(of = "id")
@EntityListeners(AuditingEntityListener.class)
public class FunctionUnit {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Version
    private Long lockVersion;

    @CreatedBy private String createdBy;
    @CreatedDate private Instant createdAt;
    @LastModifiedBy private String updatedBy;
    @LastModifiedDate private Instant updatedAt;
}
```

## 规则

| 要求 | 说明 |
|------|------|
| 表名前缀 | 见 `domain-model.mdc` 命名红线（`dw_`/`ac_`/`up_`/`we_`） |
| 时间字段 | 统一 `Instant`，不用 `LocalDateTime` |
| 乐观锁 | `@Version` + `lockVersion` 字段 |
| 审计 | `@CreatedBy`, `@CreatedDate`, `@LastModifiedBy`, `@LastModifiedDate` |
| 集合字段 | `@Builder.Default` 初始化为 `new ArrayList<>()` |
| 关联加载 | 默认 `FetchType.LAZY`，注意 N+1 查询 |
| equals/hashCode | 只基于 `id` 字段: `@EqualsAndHashCode(of = "id")` |

## DTO 配套

- 响应: `{Entity}Response`
